Original study plan and skill assessment

Four-week study plan

Use 45–60 minutes per day: 10 minutes recall, 25 minutes hands-on, 10 minutes troubleshooting notes, 5 minutes flashcards. Repeat hard cards after 1, 3 and 7 days.

Week Lesson targets Checkpoint
1 intro1, intro2, wildcard, permission, pipe Build a directory tree, filter file contents, explain 640 vs 750
2 vi, essential, admin, net Edit with vi, inspect disk/LVM, find PID and IP/route
3 SELinux1, SELinux2, fwall, DNS Identify labels, explain context persistence, test a DNS answer
4 diag, Apache1, Apache2, log, Mail Trace service failure, test Apache and explain auth/logging

Skill assessment

  • Beginner: recognize a command when shown.
  • Developing: run it with a cheat sheet.
  • Independent: choose command from an English problem and verify output.
  • Confident: explain flags, failure modes, security implications and alternatives.

For each lesson, answer 5 random cards in the browser and do the practical exercise without looking. Keep a mistakes.md in your personal notes (do not put passwords, host secrets or private logs in git).
