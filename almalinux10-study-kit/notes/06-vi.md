# 06 — The vi Editor (`vi`)

**Official tutorial:** https://linuxzoo.net/page/alma10/06-intro6.html

**Core concepts:** Modal editing, navigation, search and saving.

## Working notes

- First predict what a command will do, then run it in your **LinuxZoo AlmaLinux 10 VM**.
- Read unfamiliar syntax with `man COMMAND` or `COMMAND --help`.
- For questions that ask about your current VM, collect the answer from that VM rather than copying fixed answers.

## Command examples

```bash
# 1. vi notes.txt
# 2. i
# 3. Esc
# 4. :w
# 5. :q
# 6. :wq
# 7. :q!
# 8. dd
# 9. yy
# 10. p
# 11. /pattern
# 12. n
# 13. u
# 14. :set number
```

## Practical challenge

Open a file, insert two lines, delete one, undo, search for a word and save/quit.

## Common pitfall

Press Esc before typing colon commands; `:q!` discards edits.
